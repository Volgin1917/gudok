Методика — формализованная процедура наблюдения: что считаем, на каких данных, какими метриками удостоверяем, с какой погрешностью. Страница — основа для испытания и представления каждой методики на нашей платформе: у каждой свой паспорт (суть, вход/выход, метрики, модуль кода, оценка неопределённости) и порядок проверки на контрольной выборке из архива. Статусы честные.
Что нового в v2.0: иерархия «группа → подгруппа → паспорт» (29 подгрупп); два типа паспортов — метрика (гипотеза, формула с расшифровкой переменных, порог тревоги с обоснованием) и процедура (формальное правило, критерий корректности); новые поля — владелец-роль, зависимости, ограничения, пример расчёта «вход → выход» (обязателен для статуса «работает»), «что блокирует» для очереди; машинная валидация паспорта (validate()): не прошёл — не «работает»; глоссарий из 25 терминов и журнал изменений реестра. Снятие полных дублей и выявление «почти дублей» (репосты с правкой): шинглы + MinHash, порог Жаккара. Фундамент для каскадов и счёта «кто у кого взял».

тип: процедура · владелец: конвейер (авто) · в реестре с 17.09.2026 · последний прогон: 28.09.2026 (ежедневный конвейер)
ПравилоПары материалов: Жаккар по токенам заголовков + вложенность → union-find в кластеры. Охранные правила: обычные материалы — окно 24 ч (дословные повторы с Жаккаром ≥ 0,85 — без окна), служебные формуляры — 6 ч; повтор внутри своего издания помечается same_source и не входит в каскады; кластер несёт cluster_src — число независимых изданий (каноника — outlets.py).
Критерий корректностиF1 ≥ 0,9 на 300 размеченных парах с интервалом Уилсона; ручная ревизия 20 случайных кластеров: ложных склеек = 0.
ВходПоток материалов с текстом и временем.
ВыходКластеры дублей, канонический экземпляр, связи «источник → перепечатка».
Метрики качестваPrecision / recall / F1 на размеченных парах; доля ложных склеек.
Модуль платформыdedup.py
НеопределённостьИнтервал Уилсона 95%: при n=300 пар ±5.7 пп; F1 публикуется вместе с интервалом.

  2. Ручная ревизия 20 случайных кластеров: ложных склеек = 0.
  3. Границы кластеров сверить с прошлым прогоном.

Инфополе — это и то, что исчезает: удалённые посты, переписанные заголовки, заменённые фото. Периодический повторный обход собранных URL, сравнение хешей, фиксация дельт с таймстемпами — доказательная база сюжетов «что пытались спрятать».

ПравилоПериодический (недельный) повторный обход собранных URL: сравнение хешей контента, фиксация дельт «было → стало» (заголовок / текст / фото / удаление) с таймстемпом; удаление подтверждается повторной проверкой через 24 ч; публикация примеров — только с цитированием исходного снимка.
Критерий корректности100 URL недельного цикла: все изменения, замеченные вручную, присутствуют в журнале; каждая дельта содержит «до / после» и время.
ВходБаза URL с хешами контента и снимками.
ВыходЖурнал правок: «было → стало», тип дельты (заголовок, текст, фото, удаление), время.
Метрики качестваПокрытие графика повторных обходов; ноль пропущенных изменений в контрольной выборке.

Временные ряды упоминаний по темам и источникам; обнаружение аномальных всплесков (burst detection) — кандидатов в события дня и точки рождения сюжетов.

Метрики качестваPrecision топ-10 событий против разметки редактора; задержка обнаружения.

НеопределённостьТоп-10 из ~70 событий недели: оценка precision грубая (±10 пп) — дополняем качественным разбором каждого пропуска.

Отрицательное наблюдение: источники, которые по профилю должны писать о теме X, но не пишут. Матрица «источник × тема» и индикатор умолчания отличают «тема не поднята» от «тема замолчана» — прямой инструмент выявления границ допустимого.

тип: метрика · владелец: редакция + конвейер · в реестре с 17.09.2026 · последний прогон: 28.09.2026 (ежедневный конвейер)
ГипотезаЕсли сопоставимые по профилю источники поднимают тему, а профильный источник молчит при наличии поводов, — это сигнал границы допустимого, а не отсутствия новостей: не менее 8 из 10 таких случаев подтверждаются ручной проверкой поводов.
Формулаsilence(s, t) = 1, если expected(s, t) = 1 и actual(s, t) = 0, где expected — ожидаемое покрытие (двойная редакторская разметка, каппа ≥ 0,7), actual — покрытие темой t (М-06) в источнике s за 7 дней.
Порог тревогиМолчание ≥ 3 сопоставимых источников по теме за неделю — в блок «немые группы / умолчания» «Инфопространства»; обоснование: экспертное; реакция: ручная проверка поводов (М-14) до публикации вывода.

ВыходИндикатор умолчания по паре «источник × тема»; список систематически молчащих тем.
Метрики качестваСогласие экспертов при оценке «ожидаемого покрытия»; устойчивость индикатора между периодами.

тип: метрика · владелец: конвейер (авто) · в реестре с 17.09.2026 · последний прогон: 28.09.2026 (ежедневный конвейер)
ГипотезаИндекс виральности воспроизводит редакторский рейтинг резонанса с корреляцией Спирмена ρ ≥ 0,7 на 30 материалах недели.

Порог тревогиV в топ-3 недели — отметка «резонанс» в «Инфопространстве»; обоснование: верх распределения недели; реакция: разбор «почему резонанс» в недельнике.
ВходМетаданные (М-02), каскады (М-11), реакции.
ВыходИндекс виральности по материалам и сюжетам; топ резонансов периода.
Метрики качестваКорреляция Спирмена с редакторской оценкой резонанса ≥ 0.7.
Модуль платформыanalytics.py
НеопределённостьИндекс — относительная шкала внутри периода; сравнение между месяцами только после нормировки, метод нормировки фиксируется в журнале.
Порядок проверки на платформе
  1. 30 материалов: ранг по индексу против ранга редактора — ρ ≥ 0.7.
  2. Формула индекса и веса опубликованы, изменения — через журнал (М-28).
  3. Проверка на выбросах: один бот-всплеск не должен ломать топ.
Источник данныхdata/store.jsonl — единая база материалов (append-only; обновление ежедневно в 07:30 UTC+4; полный массив с 22.02.2026, регулярный сбор с 10.09.2026). Метаданные М-02 (просмотры, реакции), каскады М-11.
Ограничения
  • индекс — относительная шкала внутри периода: сравнение между месяцами только после нормировки (метод фиксируется в журнале)
  • один бот-всплеск не должен ломать топ — проверка на выбросах обязательна

Явка — измеритель воспроизводства легитимности: ход голосования по дням трёхдневки, разрез город/районы, сверка с прошлыми кампаниями того же типа. Мобилизация отделяется от устойчивого ядра избирателя: разница между фактической явкой и базовым профилем территории. Плотность «явления на участок» оценивается и по методу Шпилькина — диаграмма «явка × результат» по участкам с выделением ядра и «хвоста».

Гипотеза«Хвост» диаграммы Шпилькина (участки с явкой выше медианы ядра + 20 п.п.) содержит непропорционально большую долю прироста результата кампании: расхождение ядра и хвоста визуально и количественно различимо на кампании 2026.
Формулаявка = выданные бюллетени / число избирателей участка; индекс мобилизации = явка − базовый профиль территории (кампании того же типа прошлых лет); диаграмма Шпилькина — точки «явка × результат» по участкам с выделением ядра и «хвоста».
Порог тревогиУчастки «хвоста» — список «на проверку» (не обвинение); реакция: ручная сверка с первичными протоколами (М-15); сходимость пересчёта с официальными сводками ИКУО — до 0,1 п.п.

ВыходЯвка по дням и территориям; индекс мобилизации (прирост к базовому профилю); сравнение с прошлыми кампаниями; диагностика мобилизации по Шпилькину (диаграмма явка × результат по участкам).

Идеология и гегемония

сквозной раздел · 7 методик
Почему этот набор. Гегемония осуществляется не только запретом, но и согласием: региональное инфополе ежедневно воспроизводит картину мира, в которой существующий порядок выглядит естественным. Семь методик сквозного блока разбирают это воспроизводство на измеряемые механизмы: фреймы (М-21) — в каких рамках подаётся событие; голоса (М-22) — кто получает право речи, а кто остаётся объектом; собственность (М-26) — в чьих интересах пишет издание; умолчания (М-20, М-15) — что исчезает из поля и под каким статусом; язык (М-08 — классовая лексика, М-23 — дискурс-анализ) — как сам способ говорения удерживает господство; журнал (М-28) — чтобы всё перечисленное не превратилось в вкусовщину.
Границы подхода. Все семь методик — эвристики на словарной базе без морфологического парсера: точность индекса агентности ≈ 85% на ручной выборке, тон — лексиконная оценка, фреймы — маркерный скоринг, а не полное кодирование по Энтману; малые выборки качественных методик (М-23, М-15) дают интерпретацию, а не статистику. Поэтому каждый вывод идеологического блока обязан: (1) разворачиваться в список материалов — режим «доказательство» (М-18); (2) сопровождаться интервалом неопределённости или явной оговоркой; (3) не переходить границу «оценочности сверх данных»: М-15 и М-26 допускают только документально подтверждённые факты.

Стенд испытания методик

протокол за 30 секунд
Каждая методика проходит стенд до смены статуса: контрольная выборка из архива, двойная разметка, прогон модуля, метрики с доверительным интервалом против критерия приёмки, вердикт в реестр и запись в методологический журнал (М-28). Протокол ниже формируется автоматически по паспорту методики — его можно копировать и нести в рабочий журнал.


Критерий приёмкиМетодика переходит в статус «работает», если: метрики на контрольной выборке достигают порога (F1 / precision ≥ 0.80 либо совпадение с редактором ≥ 80%) с учётом доверительного интервала; повторный прогон даёт те же цифры; выгрузка выборки, протокол и запись в журнале (М-28) лежат в репозитории. Качественные методики (М-23, М-35) принимаются по процедуре двойного независимого разбора. Всё остальное остаётся в «тесте» или «очереди» — без исключений.

Термины, которые встречаются в паспортах методик и на витринах издания.
Якорь термина — #gl-<название>: из паспортов и обсуждений ссылаемся сюда.


HHI (индекс Херфиндаля–Хиршмана)
Сумма квадратов долей участников рынка (шкала 0–10000): выше 2500 — высокая концентрация. В «Гудке» — мера монополизации инфополя; считается при двух оценках охвата (М-27, волна 3).
same_source / cluster_src
Метки дедупликации: повтор внутри собственного издания склеивается для чистоты ленты, но не входит ни в каскады, ни в «также сообщили»; cluster_src считает только независимые издания (М-03, outlets.py).
TLI (индекс присутствия труда)
Доля материалов, где труд выступает субъектом речи, против упоминаний как объекта: < 0,10 — «труд невидим», < 0,30 — «труд упоминаем», иначе «труд говорит» (волна 1, М-08).
«Формально верно, контекст опущен»
Статус проверки факта (М-15): утверждение правдиво, но подано так, что ключевой контекст исчезает и смысл меняется. Требует указания, какой контекст и из какого источника.
Аспектный тон
Тональность не всего текста, а его фрагмента, связанного с конкретным субъектом — персоной или классовым актором: «о власти — позитивно, о рабочих — нейтрально» (М-05).
Двойная линейка
Типографский знак методик идеологического блока на этой странице: двойная верхняя линейка карточки. Визуальный маркер сквозного раздела «Идеология и гегемония».
Диаграмма Шпилькина
Диаграмма рассеяния «явка × результат» по участкам: однородное «ядро» и аномальный «хвост» — признак административной мобилизации (М-37, М-40).
Закон Бенфорда
Распределение первых цифр естественных числовых рядов: P(d) = log10(1 + 1/d). Отклонение — индикатор подтасовки чисел; в «Гудке» — один из цифровых тестов протоколов (М-40).
ИИ-след
Шесть признаков шаблонного (генеративного) производства текста, включая дословные повторы между источниками; отметка «подозрение на генератив» без обвинения (волна 4).
Индекс агентности
Кому информационное поле отдаёт действие: распределение материалов по классу актора и роли (субъект / объект / безличный / упоминание). Эвристика без морфологического парсера, точность ≈ 85% на ручной выборке (волна 4).
Индекс тревожности
Доля материалов с алертными маркерами (ЧП, опасность, атака) в потоке суток; один из индикаторов тона повестки (волна 1).
Интервал Уилсона
Доверительный интервал 95% для доли при данной выборке: n = 200 → ±6,9 п.п., n = 400 → ±4,9 п.п. Публикуется с каждой долевой метрикой (wilson_pp() в methods.py).
Каскад перепечаток
Цепочка материалов одного события в разных изданиях: инициатор, звенья, лаги. cluster_src — число независимых изданий каскада (М-03, М-11).
Контрольная выборка
Фиксированный набор материалов архива (n = 100 / 200 / 400, seed = 42), на котором методика испытывается до смены статуса; состав воспроизводим из архива базы.
Коэффициент Жаккара
Мера сходства текстов: пересечение множеств токенов, делённое на их объединение; ≥ 0.85 трактуется как дословный повтор (М-03).
Критерий приёмки
Единый порог смены статуса на «работает»: метрики на контрольной выборке достигают F1 / precision ≥ 0.80 либо дано явное обоснование для детерминированной процедуры (ACCEPTANCE в methods.py).
Латентность освещения
Часы от события до первой публикации: насколько поле «догоняет» реальность и по каким темам медленнее (волна 1).
Метод лидера
Кластеризация без словаря: первый материал становится лидером кластера, остальные присоединяются при косинусной близости TF-IDF-векторов выше порога (0,30 в cluster_stories) (М-06).
Минимальная выборка
Минимальный n, при котором показатель публикуется отдельной строкой: ниже порога — только накопительно или с пометкой «мало данных» (правило Уилсона).
Первичность
Доля собственных (не перепечатных) сообщений издания: основа рейтинга «сеттеров повестки» и индекса источников «первоисточник / смешанный / перепечатчик» (М-11).
Порог тревоги
Значение показателя, при котором методика обязывает к реакции: алерт, ручная проверка или редакторская помета. Всегда публикуется с обоснованием (эмпирика / экспертно / литература).
Словари классовой лексики
Редакторский словарь маркеров трудовых отношений («трудовой конфликт», «забастовка», «сокращение», «оптимизация», «коллективный договор»); частоты на 1000 слов — индикатор присутствия труда в поле (М-08).
Стенд испытания
Форма на этой странице и функция protocol() в methods.py: протокол испытания методики на контрольной выборке — выборка, seed = 42, интервал Уилсона, вердикт. Бумажный протокол и стенд не разъезжаются: оба покрыты тестами.
Федеральное эхо
Доля материалов, воспроизводящих федеральную повестку, против собственной региональной (45% / 55% на первой неделе наблюдения) (волна 1).
Фрейм
Рамка подачи события: «ЧП», «системная проблема», «успех начальства», «работы». По Энтману включает диагностический, прогностический и мотивационный компоненты (М-21).
