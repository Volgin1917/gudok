Об устройстве и границах карточки

Карточка — шаблон серверной фазы. Сейчас заполнены только сверенные реестровые поля (даты, уровень, тип, состав, ссылка на архив). Коллектор после переезда с GitHub Pages будет обходить архив ИКУО (списки, протоколы ТИК/УИК) и ГАС «Выборы» с паузами (1.2 с), цифры каждой карточки проходят сверку по протоколам перед публикацией. Ключевые методики обработки — М-37…М-41.
