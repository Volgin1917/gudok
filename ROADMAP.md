## Принципы продукта

1. **Автономность** — HTML без CDN, Python без сторонних зависимостей: работает везде.
2. **Воспроизводимость** — любой выпуск пересобирается из базы `data/store.jsonl`.
3. **Прозрачность** — каждый факт со ссылкой на первоисточник; аналитика маркирована отдельно.
4. **Вежливость к источникам** — rate-limit, честный User-Agent, кэш.
5. **Холодная голова** — алерты о угрозах только из официальных каналов (губернатор, МЧС).

## Фаза 2 — Интеллектуальная аналитика (октябрь–декабрь 2026)

**Цель: центр не только фиксирует повестку, но и объясняет её.**

- [x] LLM-слой **без внешних API** (решение заказчика от 11.09): нарратив «картина дня» пишет

## Риски и меры

| Риск | Вероятность | Последствие | Митигция |
|---|---|---|---|
| Rate-limit / бан IP у Telegram | средняя | остановка TG-сбора | задержки 1.2 c, кэш, резерв через RSSHub, фолбэк на сайты СМИ |
| Источник закрылся/изменился (кейс ulgrad) | высокая | искажение повестки | автодетекция «лента молчит/мусорит», ежеквартальный аудит источников |
| Ошибки словарной классификации | высокая | шум в рубриках | метрика точности, переход к ML-кластеризации в Фазе 2 |
| Галлюцинации LLM | средняя | репутационный ущерб | LLM только поверх фактов со ссылками; редактор подтверждает руководящий дайджест |
| Ложные алерты об угрозах | низкая | паника | алерты только из белых списков официальных каналов |
| Юридические претензии к цитированию | низкая | блокировка | только публичные данные, обязательная атрибуция, соблюдение ToS и норм цитирования |
