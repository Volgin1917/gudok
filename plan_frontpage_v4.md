# План: первая полоса v4 — реализация макета (24 предложения)

Черновик: 16.09.2026. Источник требований — «макет первой полосы с предложениями
по улучшения структуры новостей .txt» (16.09.2026). В этой записи — только
техническая сторона: что считаем, где храним, как проверяем.

## Решения редакции (2026-09-16)

1. **Подрубрики, тип, гео, статус** — сразу проектировать под переход на SQLite.
   Производные поля вычисляются и **хранятся в записи** (reclassify.py), а не только
   на лету в генераторе; generate.py читает готовые поля с fallbackом на on-the-fly.
2. **Веса скоринга** — дефолты из макета: W1=30, W2=25, W3=20, W4=15, штраф промо P=0.6.
3. **Интерактив** — прогрессивный JS: полная статика печатается без JS, JS только
   фильтрует/добирает.
4. **Объём шага** — Спринт 1 целиком (гигиена заголовков + алерт-полоса + реестр
   дублей + fallback афиши + лид-дедуп), всё с тестами.

## Целевая схема SQLite (для справки, миграция — отдельным треком)

```sql
CREATE TABLE store (
  id TEXT PRIMARY KEY,
  source_type TEXT, source TEXT, channel TEXT,
  url TEXT, title TEXT, text TEXT,
  published TEXT, fetched TEXT,
  views INTEGER,
  category TEXT, sub_category TEXT,
  topics TEXT,                       -- JSON array
  tier INTEGER,
  photo TEXT, photo_local TEXT, image TEXT,
  material_type TEXT,                -- алерт|анонс|хроника|мнение|аналитика|новость
  geo_tag TEXT,                      -- муниципалитет из config.municipalities
  trust_status TEXT,                 -- факт|по данным|не подтверждено|анонс|мнение
  xtail BOOLEAN,
  dup_of TEXT, cluster INTEGER, cluster_src INTEGER,
  same_source TEXT, also_in TEXT,    -- JSON array
  enriched BOOLEAN, enriched_at TEXT,
  web_cats TEXT
);
```

## Скоринг героя (из макета, дефолты)

```
score = W1·значимость + W2·охват + W3·свежесть + W4·источник − P·промо
W1=30, W2=25, W3=20, W4=15, P=0.6
```

- значимость: безопасность 1.0, ЖКХ 0.7, транспорт 0.65, экономика 0.6,
  политика 0.6, здравоохранение 0.55, культура 0.35, прочее 0.15 (`config.significance`)
- охват: log(просмотры), нормированный по медиане канала
- свежесть: exp(−часы/12)
- источник: tier 1 = 1.0, tier 2 = 0.7, tier 3 = 0.4

Правило стабильности: смена героя не чаще раза в 3 часа и только при перевесе ≥15%.

## Новые функции

reclassify.py:
- `compute_geo_tag(title, text, cfg)` — config.municipalities
- `compute_material_type(title, text, tier, it)` — is_alert/is_promo/CHRONO/tier
- `compute_trust_status(it)` — tier + cluster_src + material_type
- `compute_subcategory(title, text, category, cfg)` — config.subcategories

generate.py:
- `present_title(it, limit)` — эмодзи-стрип, хвосты, КАПС→строчные, ёлочки,
  обрезка по слову, достройка от предлога/союза, полная версия в `title`-атрибут
- `hero_score(it, trends, now, cfg)` — формула, fallback на поле/на лето
- `hero_stable(prev, new, now)` — 3 ч / 15%
- `fmt_time(it, mode)` — «18 мин назад» / «15 сентября» / «15.09, 22:22»
- `shown_ids_guard()` — set показанных id на страницу
- `cluster_card(members, cfg)` — лучший заголовок/фото, суммарный охват, «также сообщили»
- `fact_passport(it)` — кто/что/где/когда (agency_roles + extract_event_time)
- `quality_report(...)` — 8 метрик выпуска
